# Streamlitでグラフ作成に挑戦

---

## 概要

ノード（要素）と矢印（関係性）をブラウザ上でビジュアル操作できる有向グラフエディタです。Google Colab 上で動作し、Cloudflare トンネル経由で外部からアクセスできます。

本アプリは、ルミナイ株式会社（執筆：宮脇彰梧氏）が MIT ライセンスで公開する Python コードを基に、Google Colab で動作するよう編集したものです。

元記事: https://zenn.dev/lluminai_tech/articles/887299dcd1d90d

ナレッジグラフ（ノードと関係のネットワーク）を、コードを書かずに GUI 上で構築・編集できる Streamlit アプリです。AI が自動生成したグラフの誤りを人手で修正する Human-in-the-loop なワークフローを想定しています。

## 主な機能

- ノードの追加（空文字・重複は警告して拒否）
- ノードをクリックして始点・終点を指定し、関係名付きのエッジを作成（自分自身への接続は禁止）
- ノードの削除（接続するエッジも同時に削除）
- エッジの削除（一覧から選択して削除）
- 全データのリセット
- 現在のノード数・エッジ数の表示
- グラフデータの JSON 表示（node_link 形式）
- 選択状態に応じたノードの色分け（始点：青紫、終点：緑、通常：薄いピンク）

## 技術選定の理由

本アプリはゼロから設計せず、ルミナイ株式会社の公開コードを土台に選びました。

理由は、ナレッジグラフ（ノードと関係性のネットワーク）の構造を、実際に手を動かしながら理解するための教材として適していると判断しました。

実行環境をGoogle Colabにしました理由は、ローカル環境構築（Python環境・依存ライブラリ管理）を不要にし、ブラウザのみで動作確認できる状態を優先したためです。

外部公開にはngrokではなくcloudflaredを採用しました。

理由は、アカウント登録・トークン発行の手間なくワンコマンドでトンネルを開通できる点にあります。

## セットアップ・実行手順（Google Colab）

1. 依存ライブラリをインストールする。

   !pip install streamlit streamlit-agraph networkx -q

2. `%%writefile app.py` のセルを実行し、アプリ本体を書き出す。

3. デプロイ用セルを実行する。セル内では次の処理が順に行われる。
   1. 既存の cloudflared・Streamlit プロセスを停止する。
   2. cloudflared のバイナリをダウンロードし、`/usr/local/bin/cloudflared` に配置して実行権を付与する。
   3. `streamlit run app.py --server.port=8501` でアプリを起動する。
   4. cloudflared でトンネルを開き、標準出力から `trycloudflare.com` の公開 URL を抽出して表示する。

4. 表示された「✅ アクセスURL」をブラウザで開く。

## 操作方法

1. サイドバーの入力欄にノード名を入れ、「➕ ノードを追加」を押す。
2. グラフ上のノードをクリックし、「始点に設定」または「終点に設定」を押す。
3. 始点と終点が揃ったら関係名を入力し、「🔗 接続する」を押す。
4. ノードを削除する場合：ノードをクリックし、「🗑️ このノードを削除」を押す。
5. エッジを削除する場合：削除操作欄の一覧からエッジを選び、「🗑️ このエッジを削除」を押す。
6. 「📊 生成されたグラフデータ (JSON形式)」を開くと、現在のグラフを JSON で確認できる。
7. サイドバーの「🗑️ 全データをリセット」で全消去できる。
